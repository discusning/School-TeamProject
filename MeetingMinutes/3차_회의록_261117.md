## ■ 논의 안건

### 안건 1. 프로토타입 UI 피드백

- 논의 내용:
    - 프로토타입은 화면 배치만 바뀌고 기능은 지난번과 거의 같음
    - 노단비가 서류 연출과 대화 UI 수정을 요청, 전원 동의
    - **서류 연출**
        - 작은 서류가 위에서 아래로 내려오고 클릭하면 확대됨
        - 페이퍼 플리즈처럼 옆에서 끌어오는 방식은 쓰지 않음
    - **대화 UI**
        - 질문을 골라 누르는 대화창은 뺌
        - 대화 로그를 넣음 (왼쪽 화면을 검정 불투명으로 덮고 흰 글씨로 표시)
        - 캐릭터는 화면을 꽉 채우게 배치
    - **서류 칸 노출**
        - 나중에 추가될 서류(예: 검역 소견서) 칸은 미리 노출하지 않음 (노단비)
        - 처음부터 보이면 다음 전개가 드러남
- **결정 사항**: 위 UI 수정 반영
    - 최동환이 프로토타입 스크린샷과 기획 양식을 기획 디스코드방에 올림
    - 기획 쪽이 추가 기능·애니메이션을 정리
    - 최동환이 디자인 쪽에 전달
    - 담당자: 최동환 (공유·전달), 노단비 (정리)
    - 일정: 11/22(일)까지 프로토타입 버전 업데이트
    - 목표: 수정된 UI가 반영된 프로토타입

### 안건 2. 취조 시스템 (미확정)

- 논의 내용:
    - 대화 로그·사유서와 서류를 대조해 취조하는 방식이 제안됨
    - 페이퍼 플리즈의 방식도 예시로 나옴
        - 규칙 항목과 서류 항목을 클릭해 불일치를 찾으면 취조 대사가 자동으로 나감
    - 최동환 의견: 구현은 가능하지만 상황마다 대사를 따로 만들어야 함
        - 기획·개발 작업량이 크게 늘어남
    - 지금 확정하지 않고 검토 사항으로 둠
    - 퀄리티는 높아지고 공모전에 낼 때 강점이 될 수 있다는 의견도 나옴
    - 취조 기능 자체를 빼는 안도 함께 검토
- **결정 사항**: 취조 시스템 보류
    - 1주차 스토리·시스템이 나온 뒤 넣을지 다시 판단

### 안건 3. 그림체·캐릭터·애니메이션 범위

- 논의 내용:
    - 그림체가 제각각이면 몰입이 떨어지므로 먼저 확정하자는 최동환의 제안으로 논의
    - 결론: GPT로 뽑은 예시 그림체로 진행, 전원 동의
    - **그림체**
        - GPT로 픽셀 수를 줄이는 것은 실패
        - 아트 앱에서 픽셀 단위로 맞춰 수정
        - 노단비와 김도경이 함께 작업 (김도경은 도트 경험이 조금 있음)
        - 캐릭터를 배경에 올려 어울리는지 확인
    - **NPC 구성**
        - 주요 이벤트 인물은 6명
        - 그 밖에 일반 NPC와 입성 신청자가 많이 필요
        - 얼굴 부위별 랜덤 조합은 쓰지 않음 (결과물이 예쁘지 않고 사람을 구분하기도 어려움)
        - 일반 NPC는 머리색·눈 정도만 바꾼 양산형
        - 무채색 위주에 기억에 남지 않는 얼굴로 그려 주요 NPC와 확실히 구분
    - **애니메이션**
        - 캐릭터 애니메이션은 작업량이 너무 커서 제외 (미소 하나에 약 12프레임)
        - 서류 모션 같은 UI 애니메이션만 넣음
- **결정 사항**: GPT 그림체 확정, 캐릭터 애니메이션 제외, 일반 NPC는 개성 없는 양산형

### 안건 4. 게임 구조 및 스토리·일차 규칙 순서

- 논의 내용: 30일을 1~4주차로 나누는 데서 시작해 아래 내용을 논의
    - **20일 구조**
        - 노단비는 30일을 1~4주차로 나눠 생각함
        - 주 5일만 근무하고 주말은 건너뛰어 4주 20일로 줄이자는 안이 나옴
        - 전원 긍정적, 잠정 합의
    - **이벤트**
        - 주차마다 메커니즘을 완전히 바꾸지는 않음
        - 지루하지 않도록 이벤트에 따라 기능을 추가하거나 바꿈
        - 예: 주요 NPC 사건에 따라 기능이 생길 수 있음
        - "N일차에 반드시 일어나는 일" 같은 고정 이벤트는 노단비가 정리
    - **작업 순서**
        - 노단비가 1~5일차 규칙을 먼저 정해 둠 (1일차는 임시 통행증·서울 출신만 통과, 2일차부터 검역 소견서 추가·타지역 통과)
        - 이후 일차 규칙은 윤신재에게 맡긴 상태
        - 최동환 지적: 일차 규칙을 먼저 정하면 스토리가 규칙에 끌려가 순서가 바뀜
        - 메인 스토리 큰 틀을 먼저 정함
        - 시스템은 "들어갈 후보" 정도만 정리
    - **1주차 확정**
        - 1주차 확정 뒤 기능을 추가하면 2~3주차와 충돌하거나 작업량이 두 배가 될 수 있음
        - 확정은 신중하게 함
- **결정 사항**: 메인 스토리 큰 틀을 먼저 정하고 1주차 스토리 완성
    - 일차별 시스템은 후보 수준으로만 정리
    - 담당자: 노단비 (스토리), 윤신재 (시스템 후보)
    - 일정: 11/20(금)까지, 가능하면 11/19(목)
    - 목표: 1주차 스토리·이벤트 확정

### 안건 5. 디자인 시안 요청 및 QA 시작 시점

- 논의 내용: 최동환이 디자인 시안과 QA 시작 시점을 정리
    - **디자인 시안**
        - 캐릭터 시안은 많지만 버튼 UI·신분증 UI 시안은 부족
        - 다른 스타일로 여러 개 더 요청
        - 배경은 주차마다 한 번 바꿀 경우 4장이면 충분
        - 아침·점심·저녁 버전도 이미 있어 후순위
    - **QA**
        - 1주차 콘텐츠와 UI가 실제로 적용된 뒤 다음 주부터 시작
        - QA 보고서도 작성
- **결정 사항**: UI 시안과 일반 NPC 시안을 우선 작업
    - 최동환이 정확한 요청서를 작성해 전달
    - 담당자: 김도경 (시안), 최동환 (요청서)
    - 일정: 11/20(금)까지
    - 목표: 버튼·신분증 UI 시안 여러 종, 일반 NPC 시안
