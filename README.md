# 프로토콜: 서울 생존 구역

> 팀명: 미정 — 정해지면 여기에 반영

## 프로젝트 목표

2050년, 외부인 침략 이후의 서울 요새가 무대인 2D 싱글플레이 게임입니다.
플레이어는 요새 입성 심사관이 되어 서류를 대조하고, 사람으로 변장한 외부인을 가려냅니다.
선택에 따라 스토리 루트가 갈리고, 여러 엔딩으로 이어집니다.

- 핵심 시스템: 입성 심사(서류–주민 DB 대조), 외부인 판별, 선택지 분기·멀티 엔딩
- 참고 게임: <페이퍼 플리즈>, <That's My Neighbor Not>
- 개발 범위 기준: [게임팀플_개발범위_가이드.pdf](MeetingMinutes/게임팀플_개발범위_가이드.pdf)
