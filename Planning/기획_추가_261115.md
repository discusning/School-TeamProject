# 기획 추가 (UI 구역·판정·1·2·5일차)

## 4. 플레이어 인터페이스 (UI) 및 주요 구역

### NPC 영역 (좌측)

- 방문자 얼굴 대조: 창구에 도착한 NPC의 실제 얼굴 생김새를 관찰.
- 대화창 및 심문 상호작용: 방문자가 건네는 첫마디 확인 및 심문 대화 진행.
  - 누락 서류 요청: 방문자가 실수로 일부 혹은 전체 서류를 제출하지 않았을 경우, 대화 선택지나 빈 서류 탭을 통해 서류 제시를 요구할 수 있음. (단순 실수인 경우 당황하며 추가 제출하고, 고의 은폐·분실인 경우 핑계를 대거나 거부 사유로 이어짐)

### 서류 검토 영역 (우측 상단)

- 임시 통행증 (1차 선별소 발급): 이름, 주민번호, 생년월일, 주소, 발급일, 도장 확인.
- 검역 소견서:
  - 간이: 혈압, 맥박, 체온 확인
  - 정밀: 채혈(피의 색상, 점도 확인), 폐활량 간이 측정(폐 잡음 확인)
  - 심층: 간이 PCR(바이러스나 변이 유전자 검출), 흉부 X-ray (장기 변형 여부, 체내 이물질)
- 안 낸 서류 처리: 방문자가 서류를 누락했을 경우 해당 서류는 칸·표시 없이 없는 것으로 처리하며, 방문자에게 직접 서류를 요구할 수 있음.

### 단말기 / DB 영역 (우측 하단)

- 주민등록 DB: 이름, 얼굴, 주민번호, 주소, 범죄 이력 조회. (단, 일부 서버는 복구 진행 중 등의 연출 가능)
- 규칙 및 매뉴얼: 필수 제출 서류 목록, 위조 서류 판별 예시 및 검역 소견서 판독 기준(예: 눈 충혈은 허용, 회색빛 안색은 거부 사유 등) 열람.

### 판정 버튼 (우측)

- 최종 처분: 통과 / 거부 / 신고 / 제거 최종 처분 선택 버튼.
  - 통과: 모든 서류가 완벽한 경우
  - 거부: 임시통행증의 날짜가 지났거나, 서류 미비, 남의 통행증을 주워 온 경우 (이름, 주민번호, 주소 등 모든 게 다름)
  - 신고: 강력범죄이력이 있거나, (대화했을 때) 폭력적이거나, 서류를 위조했을 경우
  - 제거: 외형 변형, 검역소견서에 사람 같지 않은 문제점

### 1일차

- 주민등록 DB 없음
- 얼굴과 임시통행증을 보고 판단
  - 얼굴에 이상한 부분이 있는가?
  - 임시통행증의 날짜가 잘못되었는가? (임시통행증은 받은 날만 입성 가능)
  - 나이를 물어보고, 임시통행증의 나이와 일치하는가?
  - 서울사람인가? (1일차엔 서울사람만 받을 수 있도록)

### 2일차

- 주민등록 DB 복구
- 얼굴, 임시통행증, DB 보고 확인
  - 얼굴에 이상한 부분이 있는가?
  - 임시통행증의 날짜가 잘못되었는가? (현재 시간이 8월 10일인데 8월 20일에 서류 발급 받았다던지)
  - DB와 대조했을 때 문제가 없는가? (주민번호, 이름, 주소)
  - DB 복구로 모든 도시 사람 받을 수 있음.

### 5일차

- 강00, 진00 이벤트로 인해 위조서류 판별 도입
- 임시통행증의 도장 확인
